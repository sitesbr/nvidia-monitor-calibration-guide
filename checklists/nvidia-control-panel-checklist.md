# Checklist: Painel de Controle NVIDIA

## 1. Alterar resolução

Caminho:

```text
Painel de Controle NVIDIA > Monitor > Alterar resolução
```

Verifique:

```text
[ ] Monitor correto selecionado
[ ] Resolução nativa ativada
[ ] Maior taxa de atualização estável ativada
[ ] Formato de cor da saída: RGB
[ ] Profundidade da cor da saída: 8 bpc
[ ] Intervalo de saída dinâmica: Completo
```

---

## 2. Ajustar configurações de cor da área de trabalho

Caminho:

```text
Painel de Controle NVIDIA > Monitor > Ajustar as configurações de cor da área de trabalho
```

Verifique:

```text
[ ] Monitor correto selecionado
[ ] Utilize configurações de cor da NVIDIA ativado
[ ] Brilho ajustado
[ ] Contraste ajustado
[ ] Gamma ajustado
[ ] Vibração digital ajustada
[ ] Matiz em 0°
```

Perfil equilibrado:

```text
Brilho: 50%
Contraste: 50% a 53%
Gamma: 1.00 a 0.97
Vibração digital: 50% a 53%
Matiz: 0°
```

Perfil preto forte:

```text
Brilho: 50%
Contraste: 55%
Gamma: 0.95
Vibração digital: 53%
Matiz: 0°
```

---

## 3. Configurar G-SYNC

Caminho:

```text
Painel de Controle NVIDIA > Monitor > Configurar G-SYNC
```

Verifique:

```text
[ ] Habilitar G-SYNC Compatível
[ ] Modo janela e tela cheia
[ ] Ativar configurações do modelo de monitor selecionado
```

Se houver problemas:

```text
Teste apenas modo tela cheia.
```

---

## 4. Ajustar configurações de cor do vídeo

Caminho:

```text
Painel de Controle NVIDIA > Vídeo > Ajustar as configurações de cor do vídeo
```

Recomendação padrão:

```text
Com as configurações do reprodutor de vídeo
```

Se usar configurações NVIDIA, mantenha neutro:

```text
Brilho: 50%
Contraste: 50%
Matiz: 0°
Saturação: 50%
Gamma: 1.00
Intervalo dinâmico: Total 0-255
```

---

## 5. Ajustes que não devem ser usados como “solução mágica”

```text
Vibração digital muito alta
Gamma muito baixo
Contraste muito alto
HDR sempre ligado
Shadow Boost alto
Dynamic Contrast / ASCR ligado
```
